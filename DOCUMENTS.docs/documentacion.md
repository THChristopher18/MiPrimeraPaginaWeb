# Documentación del Proyecto: THCNodes

## a) EPICS
| ID | Título | Descripción |
| :--- | :--- | :--- |
| **E01** | **Gestión de Identidad** | Registro, inicio de sesión y perfil de estudiante (carrera, ciclo, datos personales). |
| **E02** | **Gestión de Contenido** | Funcionalidades para cargar, clasificar y organizar material académico por facultades y cursos. |
| **E03** | **Exploración de Conocimiento** | Interfaz para navegar la estructura jerárquica y visualizar los temas de estudio. |

## b) USER STORIES

### Epic 1: Gestión de Identidad
* **US01:** Como estudiante, quiero registrarme con mis datos básicos (carrera, ciclo, nombre), para tener acceso a los materiales de mi especialidad.
* **US02:** Como usuario registrado, quiero iniciar sesión de forma segura, para recuperar mi progreso y mis cursos guardados.

### Epic 2: Gestión de Contenido
* **US03:** Como estudiante, quiero subir archivos o apuntes a mi curso, para compartir conocimiento con mis compañeros.
* **US04:** Como estudiante, quiero organizar mis documentos dentro de una estructura de Carreras > Cursos, para encontrar mi material rápidamente.

### Epic 3: Exploración de Conocimiento
* **US05:** Como estudiante, quiero navegar por las unidades y semanas de mi curso, para seguir el orden académico de la universidad.
* **US06:** Como estudiante, quiero ver los temas específicos de cada sesión, para saber qué material necesito repasar.
